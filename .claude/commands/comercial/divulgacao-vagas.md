# Skill: Divulgação de Vagas — Conectaria

## Objetivo
Criar materiais de divulgação para vagas abertas na Conectaria: posts de LinkedIn, emails e mensagens de WhatsApp para grupos de vagas.

---

## Fluxo de trabalho

1. Receber a descrição da vaga
2. Identificar os canais necessários (LinkedIn, email, WhatsApp ou combinação)
3. Produzir cada peça no formato correto para o canal
4. Perguntar por links e valores de remuneração caso não estejam na descrição

---

## Regras gerais de escrita

- Sem travessão (—) em nenhuma peça
- Sem reticências no meio de frases
- Sem padrões de IA: frases telegráficas em sequência, paralelismos artificiais, triplas de frases nominais
- Sem hashtags em posts de LinkedIn
- Sem "Aqui na Conectaria" — referenciar sempre a mentoria
- Palavras proibidas: "crucial", "brutal", "a verdade?", "o jogo mudou", "isso muda tudo"

---

## Canal 1 — Post de LinkedIn

### Estilo de referência
Direto, com emojis informativos, setas (->) para bullets, CTA de link nos comentários.

### Estrutura
```
CARGO: subtítulo de uma linha com o diferencial

📍 Local
📝 Contratação
💰 Remuneração
🎯 Processo seletivo (resumido)

O que você vai fazer aqui:
-> atividade 1
-> atividade 2
-> atividade 3

O que a gente espera:
-> requisito 1
-> requisito 2
-> requisito 3

Frase de fechamento direta com CTA.

Candidate-se pelo link nos comentários.
```

### Variações validadas

**Versão 1 — Anúncio direto**
Apresenta a vaga sem contexto de mercado. Foco nos detalhes e no perfil buscado.

**Versão 2 — Ângulo de impacto do cargo**
Hook sobre o papel estratégico da função dentro da operação.
Exemplo: "CLOSER: quem fecha aqui não depende de desconto" — abre falando sobre o que diferencia o trabalho, não só os requisitos.

**Versão 3 — Urgência (último dia)**
Para o dia de encerramento das inscrições. Tom de "agora ou nunca".
Exemplo de abertura: "Hoje é o último dia para se candidatar à vaga de Closer na Conectaria."

> CLOSER: a Conectaria está contratando
>

> -> Capacidade de negociar sem perder posicionamento
> -> Maturidade para conduzir conversas difíceis sem travar
>

> -> Maturidade para lidar com rejeição sem perder ritmo

## Canal 2 — Email

### Estrutura com requisitos (estilo checklist)
Usado para divulgar a vaga para uma base de contatos ou lista de emails.

```
💡 Detalhes da Oportunidade:
● Remuneração: [valor]
● Formato: 100% Remoto
● Contrato: PJ

✅ Benefícios:
● WellHub (Gympass)
● Acesso a cursos e treinamentos

🔎 Principais Atividades:
● atividade 1
● atividade 2
● atividade 3

✨ Requisitos Essenciais:
● requisito 1
● requisito 2
● requisito 3

[link]
```

### Estrutura com gancho de perfil
Usada quando o objetivo é fazer o leitor se identificar antes de ver os detalhes.

```
Se você tem:
✅ requisito 1
✅ requisito 2
✅ requisito 3
✅ requisito 4

Essa oportunidade é perfeita pra você.

Descubra os detalhes abaixo! ⬇️
[link]
```

### Para duas vagas no mesmo email
Separar em seções com título em negrito para cada cargo. Repetir a estrutura escolhida para cada vaga.

### Email de urgência (último dia)
Tom direto, sem enrolação. Abertura com a informação de encerramento.
Exemplo de assunto: "Último dia — a vaga de Closer fecha hoje"
Exemplo de abertura: "Hoje é o último dia para se candidatar à vaga de Closer na Conectaria. Se você passou os últimos dias pensando 'vou mandar depois', o depois é agora."

## Canal 3 — WhatsApp (grupos de vagas)

### Regras do canal
- Máximo 4 linhas de texto + links
- Um ângulo por mensagem
- CTA sempre de link, nunca "chame no privado"
- Tom direto, sem empolgação artificial

### Para uma vaga
```
A Conectaria está com vaga aberta para [CARGO].

[Formato], [contrato], [remuneração resumida].

[Uma linha sobre o perfil buscado.]

Inscrições pelo link: [link]
```

### Para duas vagas na mesma mensagem
```
A Conectaria está com duas vagas abertas na área comercial:

*CARGO 1* — [remuneração] | [descrição curta]
Link: [link]

*CARGO 2* — [remuneração] | [descrição curta]
Link: [link]

[Contrato e formato resumidos em uma linha.]

[CTA de compartilhamento se aplicável.]
```

### Exemplo validado (Closer + SDR com urgência):
> A Conectaria está com duas vagas abertas na área comercial:
>
> 🚨 *ATÉ HOJE ÀS 18H* | CLOSER — Fixo + Comissão + Bônus | Vendas consultivas com leads qualificados
> Link: https://www.linkedin.com/jobs/view/4414354805
>
> *SDR* — R$2.000 a R$2.500 fixo + Variável | Prospecção e qualificação de leads
> Link: https://www.linkedin.com/jobs/view/4413699746
>
> Ambas 100% remoto e PJ.
>
> Se o perfil for o seu, clique no link e se inscreva. Se não for, compartilhe com quem pode ser.

---

## Perguntas a fazer antes de produzir

- Qual canal precisa? (LinkedIn, email, WhatsApp ou combinação)
- É uma vaga ou mais de uma?
- Tem urgência ou prazo para encerramento?
- Qual o valor exato do fixo? (impacta o post se quiser reforçar o diferencial salarial)
- Tem link da vaga disponível?
